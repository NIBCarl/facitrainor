Tech Stack Roles

React (Frontend) : This will manage your state for the quizzes and the progression logic. You can use React Router to protect the routes for the Admin and User pages.Supabase (Backend and Auth) :Authentication : You will use the Supabase Auth service to allow admins to create users.Database : A PostgreSQL database will store all the structured data like scores and module text.Edge Functions : These can be used to generate the PDF certificates automatically once a user finishes the program.shadcn/ui (UI Library) : This will give you high quality components like progress bars for the dashboard and cards for the module lessons.Cloudinary (Media Storage) :You will store all training videos and high resolution images here.Instead of storing the actual file in Supabase you will store the Cloudinary URL or Public ID in your database.When the page loads React will fetch the URL and display the video or image directly from Cloudinary.System Data MappingTo make this work you need a clear database structure. Here is how the tables would relate to each other.profiles : Stores user data like full names and roles (Trainee or Admin).modules : Stores the title of the daily training and the order in which they appear.pages : Stores the content for each page including the Cloudinary URL for the video.quizzes : Contains the questions and correct answers for each page.submissions : Records the scores of the trainees.attendance : Logs the timestamp when a user submits their first quiz of the day.summative_scores : Stores the physical test results that the admin encodes.Progression LogicThe system will use a simple mathematical check to allow a user to move forward. The passing score logic will look like this:$$Score = \frac{Correct\ Answers}{Total\ Questions} \times 100$$If the result is greater than or equal to $70$ the system will flag that module as completed in the database.Integration of CloudinaryWhen the admin uploads a video through the Admin Dashboard you can use the Cloudinary Upload Widget. Once the upload is successful Cloudinary returns a JSON response with the file details. You then save that URL into your pages table in Supabase. This keeps your database lightweight and your video streaming fast.
